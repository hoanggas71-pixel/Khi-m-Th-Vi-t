--------------------------------------------------------------------------------
PHẦN 2: BIÊN DỊCH BẢN CẬP NHẬT SAAS MULTI-TENANT QUA GITHUB ACTIONS (KHUYÊN DÙNG)
--------------------------------------------------------------------------------
Toàn bộ mã nguồn tính năng SaaS Multi-Tenant mới (Kiến trúc đa cơ sở, Khóa từ xa
Kill-Switch, Dev Console Tab 6, Caching Room DB SQLite, Dynamic VietQR Napas 247,
FCM Push Notification) đã được hoàn thiện 100% trong thư mục mã nguồn app/src/main/java/.

Để xuất file APK mới nhất từ mã nguồn hoàn toàn tự động mà không cần cài đặt phần mềm:
   - Bước 1: Truy cập repository dự án trên GitHub:
     https://github.com/hoanggas71-pixel/Khi-m-Th-Vi-t
   - Bước 2: Chọn thẻ "Actions" -> chọn workflow "Build Khiem Thi Viet APK".
   - Bước 3: Bấm nút "Run workflow" -> chọn nhánh "main" -> xác nhận "Run workflow".
   - Bước 4: Chờ hệ thống Cloud build hoàn tất (khoảng 3-5 phút).
   - Bước 5: Bấm vào lượt chạy vừa hoàn thành, kéo xuống mục "Artifacts" và tải về
     file "KhiemThiViet-APK.zip".
   - Bước 6: Giải nén file zip để nhận file app-debug.apk chứa trọn vẹn 100% tính năng SaaS.

--------------------------------------------------------------------------------
PHẦN 3: BIÊN DỊCH CỤC BỘ DÀNH CHO LẬP TRÌNH VIÊN (LOCAL BUILD)
--------------------------------------------------------------------------------
Yêu cầu môi trường máy tính:
   - Hệ điều hành: Windows 10/11, macOS, hoặc Linux.
   - Java Development Kit (JDK): JDK 17 hoặc JDK 21 (Temurin / OpenJDK).
   - Android SDK: Android SDK Platform 36 (minorApiLevel 1 - Android 16 Preview),
     Build-Tools 36.0.0.
   - Android Gradle Plugin (AGP): 9.1.1.
   - Gradle: 9.3.1.
   - IDE khuyên dùng: Android Studio Koala / Ladybug hoặc mới hơn.

Các bước thực hiện qua Command Line:
   1. Mở terminal tại thư mục gốc dự án.
   2. Tạo file debug.keystore chuẩn (nếu chưa có):
      keytool -genkey -v -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
   3. Thực hiện lệnh build Debug APK:
      ./gradlew assembleDebug --stacktrace
      (hoặc: gradle assembleDebug)
   4. File APK đầu ra được tạo tại: app/build/outputs/apk/debug/app-debug.apk
