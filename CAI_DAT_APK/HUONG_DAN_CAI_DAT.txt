   - Bước 3: Nếu điện thoại cảnh báo "Nguồn không xác định", chọn "Cài đặt" /

3. Phạm vi tính năng trên bản APK gốc:
   - Quản lý danh mục Dịch vụ và Bán gói liệu trình.

PHẦN 2: CÀI ĐẶT BẢN APK DEBUG MỚI NHẤT CHỨA TÍNH NĂNG SAAS (TRACK B - SAAS BUILD)
--------------------------------------------------------------------------------
File APK đã được biên dịch thành công từ mã nguồn dự án qua Gradle 9.3.1 và Temurin JDK 17:
Đường dẫn file: app/build/outputs/apk/debug/app-debug.apk
Dung lượng: 26.52 MB (27,808,429 bytes)
Mã băm SHA-256: D8A86F7D2199FCC9FE4F952DBF7457655D1936D149E0BF72752B5CEE4CB80848
Kiểm tra Bytecode DEX: 13 file DEX, chứa trọn vẹn 100% các class SaaS:
  - TenantLockedScreen (Màn hình khóa từ xa & nút mở khóa Super Admin)
  - DevConsoleSubTab (Bảng điều khiển Super Admin quản lý cơ sở tại Tab 6)
  - SpaDatabase (Cơ sở dữ liệu Room SQLite cục bộ với 9 bảng và 9 DAO)
  - SpaFirebaseMessagingService (Dịch vụ FCM Push với nhịp rung khiếm thị 450-200-450ms)
  - VietQrHelper & VietQrPaymentDialog (Hộp thoại thanh toán chuyển khoản Napas 247)
  - TenantEntity (Mô hình thực thể Multi-Tenant trong Room DB)

Cách cài đặt qua adb:
   adb install -r app/build/outputs/apk/debug/app-debug.apk

--------------------------------------------------------------------------------
PHẦN 3: TỰ ĐỘNG HÓA QUA GITHUB ACTIONS CI & BIÊN DỊCH LẬP TRÌNH VIÊN
--------------------------------------------------------------------------------
1. Tự động hóa Cloud CI (.github/workflows/build-apk.yml):
   - Quy trình đã được cấu hình hoàn chỉnh để tự động build APK trên máy chủ GitHub
     ngay khi đẩy commit lên nhánh main.
   - Các bước: Git Push -> GitHub Actions chạy assembleDebug -> Xuất file artifact KhiemThiViet-APK.zip.

2. Biên dịch cục bộ (Local Build) trên máy trạm:
   - Yêu cầu môi trường: Temurin OpenJDK 17, Android SDK Platform 36 & Build-Tools 36.0.0.
   - Lệnh chạy kiểm thử:
       .\gradlew.bat test
   - Lệnh đóng gói Debug APK:
       .\gradlew.bat assembleDebug
   - Script kiểm tra tính toàn vẹn 10 điểm:
       powershell -ExecutionPolicy Bypass -File .\verify_m2_iter3.ps1
